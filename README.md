## 一、软件简介

OPS工具包（ops-toolkit）是一款专为运维人员设计的效率工具集，集成了翻译、系统保持活跃、剪贴板监控、Teams 通知监控、待办事项管理、阿里云 SLS 日志下载分割等实用功能。

### 主要特性

- 🚀 **多翻译引擎**：支持百度翻译、腾讯翻译、阿里云翻译（需配置 API 密钥）
- ⌨️ **快捷键触发**：自定义全局快捷键，快速调用各项功能
- 📋 **剪贴板增强**：自动记录剪贴板历史，智能识别特殊内容
- 🔔 **智能通知**：Teams 消息实时监控，整点工作提醒
- ✅ **任务管理**：轻量级待办事项管理，支持到期提醒
- 📊 **日志工具**：阿里云 SLS 日志便捷下载与分割
- 💻 **系统保活**：防止电脑进入休眠状态，保持系统活跃

## 二、安装与配置

### 2.1 环境要求

- **操作系统**：Windows 10/11
- **Python 版本**：Python 3.13 或更高版本
- **屏幕分辨率**：建议 1920×1080 或更高（Teams 监控功能需要）

### 2.2 安装方法

#### 方法一：从制品库安装（推荐，稳定版本）

```bash
pip install ops-toolkit -i https://pypi.cnb.cool/leecq/pytools/-/packages/simple
```

#### 方法二：从 Git 源码安装（最新版本）

```bash
pip install git+https://cnb.cool/leecq/ops-toolkit.git
```

### 2.3 启动程序

安装完成后，会在 Python安装目录的 `Scripts` 文件夹下创建两个可执行文件：

- `ops-toolkit.exe`：GUI 主程序（推荐使用）
- `ops-toolkit-cli.exe`：带调试日志的 GUI 程序（控制台会输出调试日志）

**启动方式：**

1. 命令行中输入 `ops-toolkit` / `ops-toolkit-cli`启动程序
2. 程序将在系统托盘区显示图标
3. 右键点击托盘图标可访问各项功能

### 2.4 首次配置

首次启动后，程序会自动在以下位置创建配置文件：

- **Windows 10/11**: `C:\Users\你的用户名\.config\ops_toolkit\config.toml`

#### 配置翻译 API（必需）

翻译功能需要配置第三方翻译 API 密钥：

1. **百度翻译 API**（推荐）
    - 访问 [百度翻译开放平台](https://fanyi-api.baidu.com/)
    - 注册账号并开通"通用翻译 API"和"大模型文本翻译 API"
    - 获取 APP ID 和密钥

2. **配置 API 密钥**
    - 右键点击系统托盘图标
    - 选择"设置"
    - 切换到"API 设置"标签页
    - 点击"添加 API"
    - 选择 API 类型（如"baidu"）
    - 输入 API Key（APP ID）和 Secret Key（密钥）
    - 点击"保存"

## 三、快速入门

### 3.1 程序界面

程序采用后台托盘运行模式，主要通过以下方式交互：

1. **系统托盘图标**：右键菜单提供所有功能入口
2. **浮动窗口**：翻译结果等内容以浮动窗口形式显示
3. **设置窗口**：多标签页的设置界面

### 3.2 使用流程示例

#### 示例 1：快速翻译

1. 复制要翻译的文本到剪贴板（Ctrl+C）
2. 按下翻译快捷键（默认：`Ctrl+Alt+D`）
3. 查看鼠标位置弹出的翻译结果窗口
4. 双击翻译窗口可将结果复制到剪贴板
5. 按 ESC 键关闭翻译窗口

#### 示例 2：查看翻译历史

1. 右键点击系统托盘图标
2. 选择"翻译记录"
3. 在弹出的窗口中查看所有翻译历史
4. 可导出为 CSV 格式

#### 示例 3：开启系统保活

1. 右键点击系统托盘图标
2. 将鼠标悬停在"保持活跃"菜单项
3. 点击开启保活功能
4. 程序将监控键盘鼠标活动，防止系统休眠

## 四、功能详解

### 4.1 翻译功能

#### 功能说明

通过监听快捷键，快速获取剪贴板内容的翻译结果，支持多种语言自动识别。

#### 使用步骤

1. **复制文本**：选中要翻译的文本并按下 `Ctrl+C` 复制
2. **触发翻译**：按下全局翻译快捷键（默认 `Ctrl+Alt+D`）
3. **查看结果**：翻译结果将以浮动窗口形式显示在鼠标位置
    - 橙色文字：原文
    - 黄色文字：译文
4. **操作选项**：
    - **复制译文**：双击翻译窗口
    - **关闭窗口**：按 ESC 键或点击窗口外区域
    - **移动窗口**：拖动窗口调整位置

#### 高级功能

- **自动缓存**：翻译结果自动保存到本地数据库，相同内容无需重复调用 API
- **历史记录**：所有翻译记录都会保存，可在托盘中查看
- **语言自动识别**：自动检测源语言和目标语言
- **繁体转简体**：识别到繁体中文时自动转换为简体

#### 支持的翻译 API

| API 提供商 | 配置项     | 说明         |
|---------|---------|------------|
| 百度翻译    | baidu   | 推荐，支持大模型翻译 |
| 腾讯翻译    | tencent | 备选方案       |
| 阿里云翻译   | aliyun  | 未完全实现      |

#### 翻译历史管理

- **查看历史**：托盘菜单 → 翻译记录
- **导出历史**：在历史窗口中可导出为 CSV 格式
- **清空历史**：在历史窗口中点击"清空历史"按钮

### 4.2 Keepalive 保持活跃

#### 功能说明

监控系统键盘和鼠标活动，如果超过设定时间（默认 60 秒）无操作，将自动模拟按下 Ctrl 键，防止电脑进入休眠或锁屏状态。

#### 使用场景

- 长时间运行任务时防止电脑休眠
- 远程会议或演示时保持屏幕常亮
- Teams 监控时的辅助功能

#### 使用方法

**方法一：通过托盘菜单**

1. 右键点击系统托盘图标
2. 将鼠标悬停在"保持活跃"菜单项
3. 查看当前状态（运行次数统计）
4. 点击切换开关状态

**方法二：通过其他功能自动开启**

某些功能（如 Teams 监控）启动时会自动开启 Keepalive

#### 工作原理

1. 监听键盘和鼠标活动
2. 如果 60 秒内无任何操作，自动按下一次 Ctrl 键
3. 重置计时器，继续监控
4. 同时调用 Windows API 防止系统和显示器休眠

#### 状态查看

托盘菜单中会显示：
- 是否正在运行：`保持活跃 (True/False)`
- 已触发次数：`Ctrl 按键次数`

### 4.3 整点提醒

#### 功能说明

在每个整点时刻发出系统通知，提醒用户进行巡检或其他定时任务。

#### 功能特点

- **自定义延迟**：可设置在 N 小时后开始提醒
- **循环提醒**：每次提醒后自动设置下一个整点的提醒
- **声音提示**：使用系统通知音（Looping.Alarm8）
- **长时显示**：通知会持续显示直到用户处理

#### 使用方法

1. 右键点击系统托盘图标
2. 将鼠标悬停在"整点通知"菜单项
3. 选择提醒模式：
    - **取消**：关闭整点提醒
    - **1 小时后**：1 小时后的整点开始提醒
    - **2 小时后**：2 小时后的整点开始提醒
    - **3 小时后**：3 小时后的整点开始提醒
    - **4 小时后**：4 小时后的整点开始提醒

#### 提醒内容

通知标题：`现在是 X 点整`
通知内容：`记得要巡检啊`

#### 注意事项

- 最多可延迟 4 小时开始提醒
- 提醒会在每个整点触发，直到手动关闭
- 需要保持程序运行状态

### 4.4 剪贴板监控

#### 功能说明

后台监控剪贴板内容变化，自动记录所有文本、图片和文件信息到本地数据库。

#### 监控内容

- **文本**：完整的文本内容
- **图片**：压缩保存为 PNG 格式
- **文件**：文件路径列表

#### 使用方法

**开启/关闭监控**

1. 右键点击系统托盘图标
2. 将鼠标悬停在"记录剪切板"菜单项
3. 点击切换开关状态

**查看历史记录**

1. 右键点击系统托盘图标
2. 选择"剪切板记录"
3. 在弹出窗口中查看：
    - 时间戳
    - 内容类型（文本/图片/文件）
    - 内容预览

#### 智能识别：Aliyun SLS 链接

当检测到剪贴板中出现阿里云 SLS 下载链接时：

```
https://sls-downloaded-logs-sg.*?.aliyuncs.com/.*?\.json\.gz
```

**自动行为：**
- 自动弹出 SLS 日志下载分割窗口
- 快速开始日志下载和处理

**关闭自动识别：**

1. 右键点击系统托盘图标
2. 将鼠标悬停在"Aliyun 自动日志分割"菜单项
3. 点击取消勾选

#### 数据存储

- **数据库位置**：数据目录下的 `clipboard_history.db`
- **存储限制**：无限制（建议定期清理）
- **隐私说明**：所有数据仅保存在本地

### 4.5 Teams 通知监控

#### 功能说明

通过截图识别 Microsoft Teams 应用图标上的红色通知气泡，当检测到新通知时立即发出系统通知提醒用户。

#### 使用场景

- 多个应用窗口切换时不错过 Teams 消息
- 屏幕被遮挡时及时获知重要通知
- 需要快速响应 Teams 消息的工作环境

#### 首次配置

**步骤 1：打开配置窗口**

1. 右键点击系统托盘图标
2. 选择"Teams 通知监控"
3. 在弹出的窗口中点击"配置坐标"

**步骤 2：配置图标位置**

需要配置 4 个区域的坐标：

1. **活动图标位置**：Teams 左侧导航栏的"活动"图标
2. **消息图标位置**：Teams 左侧导航栏的"聊天"图标
3. **团队图标位置**：Teams 左侧导航栏的"团队"图标
4. **托盘图标位置**：系统托盘区的 Teams 图标

**配置方法：**

1. 点击对应的"选择 XX 图标区域"按钮
2. 屏幕会显示全屏截图
3. 拖动鼠标框选包含红色通知点的完整图标区域
4. 松开鼠标确认选择
5. ESC 键或右键取消选择
6. 重复以上步骤完成所有 4 个区域的配置

**坐标格式说明：**
```
XxY+width+height
示例："100x200+300+400" 表示从 (100,200) 开始，宽度为 300，高度为 400
```

**步骤 3：设置检查间隔**

- 默认值：30 秒
- 可调整范围：10-300 秒
- 建议值：30-60 秒

**步骤 4：保存配置**

1. 点击"保存配置"按钮
2. 配置将保存到配置文件

#### 开始监控

**准备工作：**

1. ✅ 确保 Teams 应用已打开且窗口可见
2. ✅ 确保系统音量适中（能听到提醒音）
3. ✅ 确保电脑不会自动锁屏或休眠
4. ✅ 确认图标位置与配置的坐标匹配

**启动监控：**

1. 在 Teams 监控窗口点击"开始监控"按钮
2. 阅读提示信息后点击"确定"
3. 监控状态变为"监控中"
4. 窗口会自动显示 4 个监控区域的实时截图

**停止监控：**

1. 点击"停止监控"按钮
2. 确认停止后窗口将关闭

#### 通知处理

**当检测到通知时：**

1. 系统会弹出通知窗口
2. 播放提醒铃声（如果配置了音频文件）
3. Keepalive 功能自动开启，防止电脑休眠

**收到通知后：**

1. 点击"已收到通知，停止播放"按钮
2. 或切换到 Teams 查看具体消息
3. 通知会自动停止

#### 实时监控

监控窗口右侧会实时显示：
- 4 个监控区域的最新截图
- 当前监控状态
- 运行日志

#### 注意事项

⚠️ **重要提示：**

- Teams 应用窗口必须始终可见，不能被完全遮挡
- 坐标配置需要根据实际屏幕分辨率调整
- 选择图标区域时要包含完整的红色通知点
- 保持系统音量开启，以免错过提醒
- 监控期间不要锁屏或关闭 Teams

### 4.6 待办事项管理

#### 功能说明

轻量级的待办事项管理工具，支持创建任务、设置截止时间、到期提醒等功能。

#### 功能特点

- ✅ 快速创建任务
- ⏰ 设置任务截止时间
- 🔔 到期自动提醒
- 📝 任务描述和链接
- 🗑️ 删除已完成任务

#### 使用方法

**创建任务**

**方法一：快捷键**
- 按下创建快捷键（默认 `Ctrl+Alt+T`）

**方法二：托盘菜单**
1. 右键点击系统托盘图标
2. 选择"待办事项管理"
3. 在弹出窗口中点击"新建任务"

**填写任务信息：**

1. **任务标题**（必填）：简短描述任务内容
2. **任务描述**（可选）：详细说明
3. **截止时间**（可选）：设置任务到期时间
4. **相关链接**（可选）：关联的 URL 或文件路径
5. 点击"创建"按钮保存任务

**查看任务列表**

**方法一：快捷键**
- 按下显示快捷键（默认 `Alt+T`）

**方法二：托盘菜单**
1. 右键点击系统托盘图标
2. 选择"待办事项管理"
3. 浮窗会显示所有未完成任务

**任务操作**

在任务浮窗中：

- **查看详情**：点击任务标题
- **标记完成**：点击任务右侧的复选框
- **删除任务**：右键点击任务
- **设置提醒**：在创建窗口中勾选"启用提醒"

**到期提醒**

当任务到达截止时间时：

1. 系统会弹出通知
2. 通知标题：任务标题
3. 通知内容：任务描述
4. 点击通知可打开任务详情

#### 任务管理

**删除任务**

1. 在任务列表中右键点击要删除的任务
2. 选择"删除"
3. 确认删除

**批量管理**

目前不支持批量操作，需要逐个处理任务。

#### 数据存储

- **数据库位置**：数据目录下的 `todo.db`
- **表结构**：包含任务 ID、标题、描述、创建时间、截止时间、完成状态等字段

### 4.7 Aliyun SLS 日志切割

#### 功能说明

从阿里云 SLS（日志服务）下载日志文件，并根据不同维度（Path、Hostname 等）自动分割成独立的日志文件。

#### 使用场景

- 从 SLS 下载大量日志到本地分析
- 将合并的日志文件按服务器拆分
- 批量处理 SLS 导出的 JSON 格式日志

#### 两种下载方式

##### 方式一：URL 下载（适合小量日志）

**适用场景：**
- 已有 SLS 导出的 JSON 文件下载链接
- 日志量小于 100 万行
- 快速下载单次查询结果

**使用步骤：**

1. **获取下载链接**
    - 登录阿里云 SLS 控制台
    - 执行查询语句
    - 点击"下载"→"JSON 格式"
    - 复制下载链接

2. **打开下载窗口**
    - 右键托盘图标 → "Aliyun SLS 日志切割"
    - 或等待剪贴板自动识别（如已开启）

3. **填写配置**
    - 在"URL 下载"标签页粘贴 URI
    - 选择分割选项（见下方"分割选项说明"）
    - 指定工作目录（默认：`Downloads/aliyun_sls_download`）

4. **开始下载**
    - 点击"开始下载"按钮
    - 查看左侧日志输出
    - 等待下载和分割完成

##### 方式二：SDK 下载（适合大量日志）

**适用场景：**
- 需要下载超过 100 万行的日志
- 直接连接 SLS 查询下载
- 需要灵活控制查询条件

**使用步骤：**

1. **配置访问凭证**

   在"SDK 下载"标签页填写：
    - **云账号**（可选）：用于区分不同账号
    - **AccessKey ID**：阿里云访问密钥 ID
    - **AccessKey Secret**：阿里云访问密钥密码
    - **AccessKey Token**（可选）：临时令牌

   💡 **提示**：可从环境变量自动读取
   ```bash
   ALIBABA_CLOUD_ACCESS_KEY_ID
   ALIBABA_CLOUD_ACCESS_KEY_SECRET
   ALIBABA_CLOUD_SECURITY_TOKEN
   ```

2. **配置查询参数**
    - **项目名称**：SLS Project 名称
    - **日志库名**：Logstore 名称
    - **查询语句**：SLS 查询语法（默认 `*`）
    - **开始时间**：如 `-15min`、`2024-01-01`
    - **结束时间**：如 `now`
    - **接入点**：SLS Endpoint（根据地域选择）

3. **解析并保存配置**（可选）

4. **选择分割选项**（见下方说明）

5. **开始下载**

    - 查看进度和日志
    - 等待完成

#### 分割选项说明

| 📅 移除 Path 中的日期     | 清理路径中的日期部分     | 规范化文件名   |

## 六、常见问题

### Q1: 翻译功能无法使用

**问题现象：**
按下翻译快捷键后提示"请先在设置中添加 API 密钥"

**解决方案：**
1. 打开设置窗口
2. 切换到"API 设置"标签页
3. 确认已添加至少一个 API
4. 检查 API Key 和 Secret Key 是否正确
5. 登录对应翻译平台确认账户状态和配额

### Q2: Teams 监控无法检测到通知

**问题现象：**
Teams 有通知但程序没有提醒

**可能原因及解决：**

1. **坐标配置错误**
    - 重新配置 4 个图标区域的坐标
    - 确保框选的区域包含完整的红色通知点
    - 参考示例图片进行选择

2. **Teams 窗口被遮挡**
    - 确保 Teams 窗口可见或最小化到托盘
    - 不要完全遮挡 Teams 图标区域

3. **检查间隔过长**
    - 缩短检查间隔（如改为 15 秒）
    - 但会增加 CPU 占用

4. **屏幕缩放问题**
    - 如果使用了屏幕缩放（如 125%、150%），可能需要重新配置坐标
    - 建议在固定缩放比例下配置

### Q3: Keepalive 失效

**问题现象：**
电脑仍然进入休眠或锁屏状态

**可能原因：**

1. **组策略限制**
    - 某些公司电脑的组策略禁止程序阻止休眠
    - 联系 IT 部门确认

2. **电源管理设置**
    - 检查 Windows 电源选项设置
    - 确保"关闭显示器"和"使计算机进入睡眠状态"设置为"从不"

3. **程序未正常运行**
    - 查看托盘菜单中 Keepalive 的状态
    - 确认显示为 `True`

### Q4: 剪贴板监控占用过高

**问题现象：**
内存或 CPU 占用持续升高

**解决方案：**

1. **限制监控内容**
    - 考虑关闭图片监控（如有此选项）
    - 定期清理剪贴板历史

2. **检查数据库大小**
    - 查看 `clipboard_history.db` 文件大小
    - 如过大可考虑清空历史

3. **重启程序**
    - 退出程序重新启动
    - 释放占用的资源

### Q5: 待办事项提醒不响

**问题现象：**
任务到期但没有收到提醒

**检查项目：**

1. **系统通知权限**
    - 确认 Windows 允许应用发送通知
    - 检查"专注助手"设置

2. **提醒是否启用**
    - 创建任务时勾选"启用提醒"
    - 查看任务列表中的提醒状态

3. **程序运行状态**
    - 确保程序在后台运行
    - 查看托盘图标是否存在

### Q6: 开机自启失败

**问题现象：**
勾选开机自启后重启无效

**可能原因：**

1. **注册表权限**
    - 程序需要写入注册表：`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
    - 某些安全软件可能阻止

2. **启动文件夹限制**
    - 检查组策略是否限制启动项
    - 查看启动文件夹是否有冲突

3. **配置未保存**
    - 确认点击了"保存设置"
    - 查看配置文件中 `startup` 字段是否为 `true`

### Q7: SLS 日志下载失败

**问题现象：**
点击下载报错或无响应

**检查项目：**

1. **网络连接**
    - 确认能访问阿里云 SLS 服务
    - 检查防火墙设置

2. **AccessKey 有效性**
    - 登录阿里云控制台验证 AK/SK
    - 确认账户有 SLS 访问权限

3. **查询参数**
    - 检查 Project 和 Logstore 名称是否正确
    - 确认时间范围有效
    - 验证 Endpoint 与地域匹配

4. **磁盘空间**
    - 检查工作目录所在磁盘有足够空间
    - 大量日志下载前先估算大小
